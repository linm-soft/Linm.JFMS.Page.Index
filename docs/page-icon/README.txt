page-icon package (static Page.Index)
=====================================

Chỉ 2 file — user ghi đè tùy brand:

  title.png   ← favicon / tab title (logo title)
  login.png   ← logo hiển thị trên page (nav)

HTML:
  <link rel="icon" href="page-icon/title.png"/>
  <img src="page-icon/login.png" alt="..."/>

Starter seed (xóa/ghi đè thoải mái):
  title  ← logo-64 từ web-icon
  login  ← logo-login từ web-icon
